🛠️ Основной функционал плагина
1. Кастомные роли персонала и система квалификации
2. Иерархия отделов: Добавляет множество полноценных ролей для четырех департаментов: Научного (от интерна до директора), Медицинского, Инженерного и Службы Безопасности.Прогрессия по часам: Доступ к более высоким должностям (например, Начальник СБ или Научный Руководитель) автоматически блокируется, если игрок не наиграл нужное количество минут/часов за конкретный филиал.
3. Уникальные имена: Игрокам автоматически генерируются реалистичные RP-имена в зависимости от их класса (например, «Д.Р. Абрамов» для Директора Зоны или «D-4821» для Д-класса).
4. Персональные ключ-карты: При спавне кастомные роли получают уникальные по цвету, названию и уровням допуска ключ-карты, на которых отображается их имя.
5. Инструменты и механики взаимодействия (Server-Specific UI). Плагин интегрирует в движок игры меню из 6 быстрых клавиш (Keybinds) для выполнения RP-команд.
6. Специальное оборудование и кастомные предметы.
7. Глобальные механики раунда.
